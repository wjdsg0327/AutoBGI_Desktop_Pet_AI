# 关键词自定义音效审查

**审查范围**

本次审查覆盖每条关键词规则独立的音效开关、五种内置芙宁娜 MP3 语音和共享用户自定义 WAV 素材的选择、持久化、试听、触发、清除、升级与失败恢复。

**实现决策**

- 自定义音效只接受 PCM WAV：不超过 10 MiB，最长 30 秒，8–96 kHz，单声道或双声道，支持常见 8/16/24/32 位采样。
- 用户文件复制到当前用户的 `AutoBGI-Pet` 应用数据目录，内部固定文件名为 `keyword-sound.wav`；规则只保存展示用文件名和 `custom` 类型，不保存外部绝对路径。
- 五种内置 MP3 通过 `go:embed` 写入程序，Windows 使用自带的媒体解码接口播放；自定义 WAV 继续使用 Windows 原生播放接口；非 Windows 保留空实现以便跨平台编译。
- 自定义文件替换和清除使用原生操作门禁；试听、替换和清除前都会停止异步 WAV 播放。
- Windows 试听和关键词触发使用同一条串行播放请求门禁；非 Windows 试听会明确返回“不支持”，不会伪装成已播放。

## P1 发现与处理

以下三项 P1 风险已在实现中处理。

### F-01：外部文件输入可能带来路径、链接和资源消耗风险

**处理**：选择时拒绝目录、符号链接、非 WAV、超过 10 MiB、RIFF/WAVE 结构无效、非 PCM、参数超限或超过 30 秒的文件；打开和读取前后核对同一文件，复制后只使用应用数据目录中的固定文件。

### F-02：配置落盘失败可能造成“配置与音频文件”不一致

**处理**：自定义音效替换和清除都保存旧配置与旧 WAV 快照；任一配置保存失败时恢复内存字段和旧文件。前端通过统一错误出口显示失败，保持原音效选择。

### F-03：启动时自定义文件可能已经被删除或损坏

**处理**：启动检查内部 WAV；文件缺失或损坏时自动回退到默认的安静陪伴语音、清空展示文件名并写入提示，不阻塞连接、桌宠动作或气泡。

## P2 边界与恢复

- 选择器取消不改变当前规则音效；重复打开选择器会被门禁拒绝，完成后可重试。
- 文件被其他程序替换、删除、静音或 Windows 音频服务不可用时，动作和气泡仍照常完成，只跳过声音。
- 同一 `attempt` 只有一次首帧确认，重复回调不会叠加播放；`eat` 拾取动作、关闭开关、勿扰、隐藏桌宠、关闭气泡和系统休眠均不播放。
- “清除自定义音效”只清除共享 WAV，并将依赖它的规则回退到安静陪伴语音；删除权限不足时保留现状并允许用户重试。
- 发布压缩包不包含用户音效，升级后应用数据目录中的有效音效继续可用。
- 内置 MP3 首次播放时提取到当前进程的临时目录，桌宠退出时会停止播放并清理该目录；系统强制终止进程时由操作系统保留临时文件，下一次可手动清理。

## 验收标准

### Given/When/Then

1. **选择有效 WAV**
   - Given 用户在关键词音效素材区域选择符合限制的 PCM WAV
   - When 选择器确认文件
   - Then 文件复制到应用数据目录，用户可以在任意规则中选择 `custom` 类型，界面显示文件名并允许试听当前规则。

2. **拒绝无效文件**
   - Given 用户选择目录、链接、非 WAV、损坏 WAV、超大或超时长文件
   - When 桌宠校验文件
   - Then 不替换当前文件和配置，界面显示可恢复错误。

3. **触发时机**
   - Given 当前规则开启音效且选择 `custom`，自定义文件有效
   - When 普通关键词动作完成首帧确认
   - Then 播放一次当前规则选择的自定义音效；重复首帧回调、拾取动作、隐藏、勿扰或休眠不播放。

4. **清除与恢复**
   - Given 一条或多条规则选择了自定义音效
   - When 点击“清除自定义音效”
   - Then 自定义文件删除，依赖它的规则回退到安静陪伴语音，其他规则的内置语音设置不变。

5. **失败回滚**
   - Given 文件复制成功但配置保存失败，或删除成功但配置保存失败
   - When 桌宠处理保存错误
   - Then 恢复旧文件和旧配置，当前界面状态保持原选择。

6. **旧配置迁移**
   - Given 配置文件只有旧版全局音效开关、类型和自定义文件名
   - When 新版本首次读取配置
   - Then 将旧设置复制到每条规则；全局字段仅保留兼容，不再参与后续规则触发判断。

7. **规则级隔离**
   - Given 规则 A 开启开心语音，规则 B 开启难过语音，两个规则的关键词和顺序均有效
   - When 日志分别命中规则 A、规则 B，并各自完成一次首帧确认
   - Then 第一次只播放开心语音，第二次只播放难过语音；同一规则的重复首帧回调不重复播放。

8. **规则字段优先**
   - Given 配置同时存在与规则选择不同的旧版全局音效字段
   - When 新版本读取并保存已有规则
   - Then 已存在的规则级开关和类型保持不变；只有缺少规则音效字段的旧规则才使用全局字段完成一次迁移。

## 发布边界

本地 Go 测试、Windows 交叉编译、`go vet`、前端类型检查和生产构建可以证明校验与绑定没有编译回归；它们不能替代在真实 Windows 主机上试听、触发、系统静音、文件删除权限和托盘生命周期的手工验收。
