### 自动化覆盖与清理

后端检查覆盖固定 `apiKey`、请求路径与基础前缀、重定向拒绝、HTTP/HTML/JSON 边界、旧版任务状态不推断、协议降级、401 停止、迟到 A 回包不覆盖 B、配置备份损坏恢复。
Windows Credential Manager 使用随机的本程序凭据引用进行了真实写入/读取/删除往返，不使用用户生产 APIKey；这不代替“退出客户端后重新打开”的端到端验收。
后续追加的 6 项事务/并发检查使用 `go test -race -count=1 -v ./internal/service`：凭据修改或删除后 JSON 保存失败恢复旧密钥，会话切换保存失败保留旧密钥，补偿失败时旧密钥仅保留会话并显示 notice，100 个并发状态 revision 单调，以及恢复快捷键白名单。对应 `transaction_tmp_test.go` 和先前 4 个临时后端测试文件均已删除。
前端检查覆盖受限素材路径、越界帧、DPR 上限、隐藏 RAF 暂停、短动作回落、卸载清理、generation/配置列表隔离和浏览器模式无网络绑定。
本次测试完成后删除临时测试源，保留准确记录；不删除 AutoBGI 主项目原有测试。

独立审查后补齐了通知窗口/计时器的并发锁与通知代次、退出后排队回调失效、设置保存失败不修改原生状态，以及每次启动的可见面板恢复入口。
拖动改为前端按指针位移调用 `BeginPetDrag`/`DragPetTo` 移动窗口，不再进入系统 modal 移动循环，避免拖动期间独占全局鼠标捕获导致桌面无响应；该改动待 Windows 原生实机复测。
上述修复完成后重新执行指定工具链编译与 desktop 静态检查；未将无 GUI 的编译检查写成原生窗口通过。
