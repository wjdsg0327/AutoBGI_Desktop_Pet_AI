# AutoBGI 桌宠 · 叶芽

独立运行的 Windows 桌面小助手，使用 Go + Wails v3 + Vue 3 + TypeScript。
所有桌宠源码、素材、构建脚本与文档均位于本目录，不修改 AutoBGI 主项目工具链，也不要求大模型 API。

## 当前交付范围

当前构建为 **0.2.14 阶段性增强版**，在原有独立桌宠上接入 M3 命令与事件及 M4 已有业务数据：

- 原创精灵图角色、透明角色窗、独立气泡窗与信息面板。
- 拖动（前端按指针位移移动窗口，不占用系统鼠标捕获）、置顶、缩放、位置保存与工作区纠正、整窗鼠标穿透及托盘恢复。
- 多份连接资料、同一时间一个活动连接，支持固定反向代理基础路径。
- Go 层发送 `apiKey`，Windows Credential Manager 保存密钥，或明确选择仅本次会话使用。
- 运行概览、5/15 秒自适应轮询、网络退避、鉴权失败停止重试、历史快照过期提示。
- 不需要模型的规则查询：当前状态、有哪些一条龙、打开 AutoBGI 等。
- 一条龙配置列表、默认仅查询模式、60 秒一次性确认、实例与配置前置条件校验、持久命令回执。
- 新服务端提供原子登记的幂等启动：同一命令号最多派发一次，不关闭已有 BGI、不自动重试；不确定结果仅查询原回执。
- 单条 SSE 事件流、持久游标与通知尝试记录、断线重放及游标失效后的快照补偿。
- 按需读取真实摩拉收益、背包扫描档案和培养需求缓存；分别标明角色、扫描时间、数据范围及未知数量。
- 从已有米游社绑定缓存选择只读查询角色，按 UID 与区服核对收益和培养归属，角色切换时立即清除旧摘要。
- 按真实一条龙预设读取正式保存的培养队列，展示绑定身份、顺序、明确目标和精确需求缓存；版本使用字符串，库存未核验时保持未知。
- 普通轮询、事件重同步和启动确认共用可取消的快照门，拒绝同一连接内较旧样本回写。
- 通知按错误、命令结果和普通状态排序，五秒依次显示、进度合并、超量摘要；勿扰结束只显示一条摘要。
- 原生连接资料 JSON 导入导出，严格脱敏、整批校验；导入后需要重新填写密钥，默认仅查询且关闭自动连接。
- 本地 PNG 精灵皮肤 ZIP 导入与切换，校验图片、清单和许可；切换失败保留可用图集，内置角色始终可恢复。
- Windows 网络接口和地址变更监听，断网与系统休眠分别暂停；回环连接不受外部网络离线影响，恢复先重同步。
- 控制台独立显隐状态、按需运行的启动确认倒计时；隐藏、休眠和确认过期后停止计时，恢复时重新校验期限。
- 桌宠与气泡补充鼠标悬停、触摸指针的激活拒绝消息处理，保留点击和拖动输入；真实游戏焦点仍待原生验证。
- 培养材料结果的持久接收与只读历史补偿；按原计划、UID/区服和发生时间展示，重连历史不补弹气泡，不将材料满足解释为游戏升级完成。
- 恢复快捷键区分已保存选择和实际注册组合，支持冲突后重试；动画按素材帧率等待绘制，本地 PNG 验证采用完整内容摘要的有界缓存。
- 本地通知收件、已读与勿扰计数随事件一起原子保存；重启可查历史，恢复勿扰仅显示当前来源的一条未读摘要，面板提供显式已读操作。
- 当前来源的未读错误驱动角色警告；正文清理后独立保留错误数量和发生时间，用户显式确认后按最新事实回落。
- 单击显示配置、路线与采集时间，原生菜单直达状态、连接和通知记录；运行时按原显示器的新工作区保持相对位置，原显示器移除明确回退主屏。

## 环境要求

- Windows 11 x64 为首发目标；Windows 10 需单独实测。
- Microsoft Edge WebView2 Evergreen Runtime。系统缺失时请使用 Microsoft 官方安装程序安装。
- 开发构建需要 Go；项目 `go.mod` 锁定 Go 1.26.0 语言基线、Go 1.26.10 工具链。
- Node.js `>=22.12.0`、npm `>=10`。本次开发环境为 Node.js 24.21.0 / npm 11.19.0。
- 首次构建可访问 Go/npm 包源，用于下载指定工具链与锁定依赖。

Wails CLI 固定为 `v3.0.0`，安装到本目录 `.tools/`，不覆盖用户全局 CLI；前端 runtime 固定为 `3.0.0`。

## 构建与运行

以下 PowerShell 命令均在本目录执行：

```powershell
# 安装锁定依赖、生成原创素材和 Go 绑定，再构建 Windows 便携程序。
.\scripts\build.ps1

# 直接运行生成的客户端。
.\bin\AutoBGI-Pet.exe

# 生成带说明与许可证的便携 ZIP。
.\scripts\build.ps1 -Package

# 在独立目录构建新阶段，保留已有版本及其发布暂存目录。
.\scripts\build.ps1 -Package -OutputDirectory bin/0.2.14

# 完整构建后以 Go 调试宿主运行；不是仅浏览器演示。
.\scripts\dev.ps1
```

默认输出：`bin/AutoBGI-Pet.exe`，可选便携包 `bin/AutoBGI-Pet-0.2.14-windows-amd64.zip` 及 SHA-256 校验文件。本阶段保留旧默认输出，交付的新程序和便携包位于 `bin/0.2.14/`。
便携包无需管理员安装；当前脚本不是 MSI/NSIS 安装器，不包含自动更新或签名发布流程。
便携包包含 `docs/`、第三方许可证、内置素材许可及 `bgi/AutoBGIInventoryEvidence/` 采集脚本；真实采集请求和回执不进入发布包，其他源码和构建脚本位于完整源码目录。
不要以管理员权限运行桌宠来解决连接问题。

`build.ps1` 临时设置 `GOTOOLCHAIN=go1.26.10` 与项目本地 `GOBIN`，清除继承的 `GOROOT` 后解析并固定该工具链根目录，完成后恢复环境。调试入口采用同样的工具链隔离，避免与主项目 Go 版本混用。
它通过 Wails `generate bindings -ts -i` 从 Go 重新生成 `frontend/bindings/`；不要手工修改生成绑定。
最终构建使用 production 标记、trimpath 和 Windows GUI 子系统，嵌入 Vite 输出，不依赖旁边的前端文件夹。

## 首次连接

1. 启动客户端，打开“连接”页，新建连接资料。
2. 默认地址提示为 `http://127.0.0.1:8082`，按实际 AutoBGI 服务地址修改；不会扫描局域网或尝试默认密码。
3. 填写 **AutoBGI APIKey**，它来自服务端 `abgiUser.yaml` 的 `auth.api_key`，不是联机 SecretKey 或模型密钥。不要把值提交到仓库。
4. 默认保持仅查询模式。选择保存到系统凭据，或勾选仅本次会话使用，然后保存并连接。
5. 概览展示当前实例、原始进度和采集时间；`running` 只表示 BGI 进程存在，不表示一条龙正在执行，也不能证明任务成功。

“自动”协议先尝试桌宠 capabilities；仅明确接口不存在时才验证 legacy。本次增加了桌宠 v1 路由；尚未更新服务端时仍可使用 legacy 查询。
若部署的反向代理将未知接口改成 HTML 页面，客户端会明确报不兼容；可在确认目标确为当前旧版本后手动选择 `legacy`，而不是关闭鉴权或 TLS。

远程连接默认要求 HTTPS。局域网明文兼容需要显式启用，并使用允许的内网 IP；这会明文传输 APIKey。
不支持 userinfo、查询参数、片段或跳转地址；重定向不会转发密钥。

## 桌面操作

- 单击角色：挥手并显示当前状态摘要；双击角色：打开控制台。
- 已有活动连接资料和持久凭据引用时，启动只创建角色，控制台在主动打开时创建。首次设置、活动资料失效或会话密钥需要重新输入时会显示控制台；托盘初次创建失败也会打开控制台并保留告警。持久凭据引用存在不保证密钥仍可读取，连接结果以实际鉴权为准。
- 拖动角色：只移动角色窗口，不进入系统 modal 移动循环、不发业务请求；右键：显示原生菜单。
- 托盘：显示/恢复交互、关闭穿透、重置位置、打开控制台、打开 AutoBGI、断开、退出。
- 恢复快捷键默认 `Ctrl+Shift+P`，设置可切换三组受限组合；面板展示实际注册结果。冲突时保留原组合，可在占用释放后点击重试，也可使用托盘恢复交互。
- 隐藏角色：停止绘制，保持连接；关闭面板：隐藏面板；断开连接：取消网络；退出：清理宿主及采集任务。
- 关闭后的控制台保留未保存的输入与 WebView；面板里的角色预览只绘制静态首帧。角色、气泡和控制台分别加载自己的前端视图。
- 开启整窗穿透后，角色不接收点击，可从托盘或恢复快捷键关闭。CSS 透明不等于原生穿透。
- 位置异常时使用托盘“重置桌宠位置”；原显示器消失时按实际工作区恢复。
- 普通点击摘要不能覆盖正在显示的错误或启动回执。拖动只收起当前气泡，后续提醒继续排队；屏幕位置自动纠正只移动气泡。
- 勿扰期间累计提醒，关闭勿扰后显示一条摘要；隐藏、休眠或关闭气泡期间的提醒不会在恢复时补弹。
- “桌宠设置 → 角色外观”支持本地导入并使用，完整格式及限制见 `docs/skins.md`。自定义皮肤只描述图像与帧动画。
- 系统明确没有可用非回环网络接口时暂停远程连接；接口恢复后重新读取完整状态再订阅事件。检测只读取本机接口，不向互联网探测；有局域网接口不等于服务地址可达，服务不可达仍使用原退避逻辑。

规则问答不会根据“停一下”“启动那个”等模糊文本执行动作。收益或培养数据不可用时会解释缺口，不显示虚假零值。

## 启动与业务摘要

需要启动时，在连接管理中编辑当前连接，明确关闭“仅查询模式”，然后到“一条龙配置”读取配置、点击“准备启动”。确认卡冻结目标地址、实例、配置和影响，有效期 60 秒。确认只消费一次；切换连接、密钥或执行条件变化后需重新准备。

只有 Pet V1 同时声明幂等与命令查询能力才开放启动；Legacy 始终只读。已有 BetterGI 进程或无法核实进程状态时拒绝启动。启动回执 `succeeded` 只表示单次启动动作已提交，不代表游戏任务完成。超时、断线及崩溃后结果未知时，查询原命令并核对 AutoBGI，不自动重新发送。

概览下方点击“读取业务摘要”读取已有数据，不触发扫描、签到、远程刷新或培养执行。“今日收益”由服务器确定当天日期，并显示来源时区。背包可选择实际扫描档案并筛选材料；缺席条目保持未知。培养目标若来自计算器默认值会明确标注，需求仅使用现有算法缓存。日期、时区、归属与限制见 `docs/domain-audit.md`。

服务端声明 `queryRoles` 时，摘要内可选择绑定缓存中的查询角色；选择只影响收益和培养面板，不切换游戏账号，也不更改一条龙目标。列表显示缓存时间和来源；缓存不代表当前登录身份或凭据有效。失效角色不会自动改用默认角色。扫描档案尚无可信角色绑定，因此角色模式培养的已有材料和缺口保持未知，独立背包仍可查看。旧服务缺少角色能力时继续按原默认角色查询。

服务端另行声明 `cultivationQueue` 时，概览增加“已保存培养队列”。先读取服务端配置列表，再明确选择一条龙并读取；不会自动选择默认配置。正式队列使用自身保存的 UID/区服，与上方查询角色无关。列表刷新或读取失败保留同一连接的历史结果并标记过期；切换连接、实例或配置会清除旧结果。该入口只读，编辑仍在 AutoBGI 的一条龙配置页；队首不代表正在执行，空队列不代表“全部完成”。旧 `/cultivation-plans` 继续展示旧配置与需求缓存。

## 配置与凭据

非敏感配置保存在系统返回的当前用户应用数据目录，Windows 通常是 `%APPDATA%\AutoBGI-Pet\`：

- `config.json`：连接资料与偏好；同目录临时文件原子替换，保留有效配置备份。
- `config.json.bak`：最近有效配置备份，损坏时用于恢复。
- `position.json`：逻辑坐标、显示器标识与相对工作区位置。
- `snapshot-cache.json`：有上限的历史运行快照，离线展示时标记过期。
- `command-event-journal.json`：命令意图、回执、SSE 与材料历史独立水位、稳定业务去重及通知尝试状态；不保存 APIKey。
- `skins/`：经过校验的本地皮肤，每套仅有清单、PNG 和许可文本。

APIKey 不写入以上 JSON、localStorage、日志或发布包。系统凭据引用使用 `AutoBGI-Pet/profile/<随机ID>` 命名空间。
保存凭据失败会明确报错，用户可选择会话模式；不会偷偷明文落盘。会话模式关闭后需要重新输入，不会下次自动连接。
断开不会删除系统凭据；删除连接资料才清理对应凭据。

连接页的“迁移连接资料”使用原生选择/保存对话框。导出 JSON 仅有名称、地址和适配器等白名单设置，不含密钥、凭据引用、ID、历史缓存或皮肤。导入不超过 64 KiB，一次先校验全部条目再原子追加，总数最多 20。全部条目采用新 ID，强制仅查询、关闭自动连接；点击“编辑”重新填写密钥后才能连接，并自行选择保存到系统或仅本次会话使用。导入不会切换当前连接或访问系统凭据。

系统凭据保护并不阻止同一用户权限下的恶意进程。请勿将配置备份、运行截图或诊断输出当作绝对保密渠道。
开启登录启动会写当前用户 Run 项；便携移动路径或删除程序前，应先在客户端关闭登录启动。
便携卸载只需退出并删除程序；需要同时清理本地资料时，先在客户端删除连接并关闭登录启动，再按需删除用户配置目录。

## 项目结构

| 位置 | 职责 |
| --- | --- |
| `main.go` | 宿主、绑定白名单、可信资源、安全响应头、单实例与退出 |
| `internal/desktop/` | 三类窗口、托盘、点击穿透、工作区与位置 |
| `internal/autobgi/` | 固定来源 HTTP、Legacy 查询、PetV1 命令/SSE/领域适配器 |
| `internal/service/` | 连接状态机、唯一采集器、确认令牌、持久回执、规则查询与通知 |
| `internal/notification/` | 通知优先级、有限队列、去重、聚合与勿扰策略 |
| `internal/skin/` | 本地皮肤 ZIP 校验、原子安装与固定同源资源读取 |
| `internal/profile/` / `internal/storage/` | 脱敏资料、版本化配置、备份与原子写入 |
| `internal/credential/` / `internal/platform/` | Windows 凭据与显式登录启动设置 |
| `frontend/src/` | Vue 面板、连接页、Pet/Bubble 视图、Pinia 与 Canvas renderer |
| `cmd/assetgen/` / `assets/pets/default/` | 可复现原创精灵、协议与 CC0 声明 |
| `scripts/` | 指定工具链的构建、运行与便携打包 |
| `docs/` | 实际 API 审计、兼容规则、验收记录及许可证 |
