# 培养基础目标达标通知

日期：2026-10-28。本阶段继续开发冻结 0.2.14 之后的源码，贯通领域事务、独立 HTTP 历史、桌宠持久补偿和历史界面。没有更新 `bin/0.2.14/` 的程序或便携包。

## 事件含义与双时间

目标事件使用 `talent.entry.targets-met` 和 `talent.queue.targets-met`，表示冻结来源中的角色基础等级与明确天赋目标已经达标。它不证明本次启动完成了培养，也不证明游戏任务执行成功。

每条历史固定原操作、执行目录、计划、配置、UID/区服、稳定条目和计划版本。条目事件包含原角色，队列事件不填写角色条目字段。两种时间分别展示：

| 字段 | 来源与含义 |
| --- | --- |
| `observedAt` | 冻结可信基础面板的 `SourceTime`，表示何时观察到目标状态 |
| `occurredAt` | 队列终态事务的提交时间，表示何时登记该达标事实 |

两个时间必须有效、年份至少为 1，且 `observedAt <= occurredAt`。读取历史不会刷新观察时间。界面与普通提醒明确区分观察和登记时间，不播放庆祝动作。

## 启动版本与兼容

| 启动模式 | 来源开关 | 持久版本 | 事件行为 |
| --- | --- | --- | --- |
| 旧材料模式 | `TargetEventsVersion = 0` | schema 1 | 保持原材料事件与原冻结正文 |
| 基础面板 `panel-targets` | `TargetEventsVersion = 0` | schema 2 | 保持无事件，不补发历史通知 |
| 基础面板 `panel-targets` | 宿主明确提供 `TargetEventsVersion = 1` | schema 3 | 最终事务写入独立目标事件 |

新开关只由宿主来源提供，HTTP 调用方不能请求升级。冻结正文、行版本、模式和开关必须一致；未知版本及不相容组合被拒绝。schema 2 不会因为升级程序而转成 schema 3，历史达标记录不回填。

schema 3 仍需完整计划、可信身份、源时间、明确元素和 A/E/Q 技能绑定及全队列精确覆盖。现有只读展示缓存不能成为可信来源；实际生产 `StartSource` 仍不可用。

## 独立持久历史

目标历史使用独立的 head、generation、sequence 和投影表，不复用材料流的游标。来源 outbox 不增加观察时间列，目标接收器重新校验 schema 3 冻结记录后推导 `observedAt`。

每个接收器只处理自己的两种事件，共用的有界检查拒绝未知或 NULL 的未确认事件类型。每轮每类最多接收 256 条；投影、序号推进和源确认在同一 SQLite 事务提交。重试、重复接收和进程重建保留同一业务身份。

宿主保持一个接收协程、一把执行目录队列锁。两类历史独立提交；其中一类失败时仍尝试另一类，已提交的历史仍发送兼容的 `server.notice` 唤醒，错误保留并限频提示。关闭会取消并等待当前接收完成。

## HTTP 合同

能力名为 `targetsMetEvents`，入口为 `GET /api/desktop-pet/v1/cultivation-target-events`。完整字段与错误规则以 `api-v1.openapi.yaml` 为准。

首次读取不带增量参数；后续必须同时提供 `executionContext`、`generation` 和 `after`。游标、序号和计划版本使用规范十进制字符串，单页最多 100 条。目录或代次变化、游标失效返回 410 并要求重新建立历史基线。未知、重复或空查询参数被拒绝。

材料接口、材料 DTO 和 SSE 事件格式保留原合同。目标接口本身只读，不执行培养、出队或游戏启动；仅增加历史能力不代表开放执行能力。

## 桌宠补偿与展示

客户端继续使用唯一轮询循环。目标历史按连接资料、基础 URL、实例、执行目录和独立代次隔离，切换来源、暂停或停止之后，迟到结果不能写回。初次基线、断线恢复及重同步仅补充历史；当前来源的新增事件按业务身份去重，可靠保存后才尝试普通提醒。

本地 journal 保持 schema 1，新增 `targetScopes,omitempty`。旧日志缺少该字段仍可读取；出现该字段时执行严格正文和一致性校验。该兼容方向不保证旧版 0.2.14 程序能够读取已含新字段的日志，降级前应保留原日志副本。

目标流独立保留最多 10 个来源范围、每个范围 100 条历史和 4096 个已处理标记，沿用 16 MiB 日志文件上限。裁剪、保存、深拷贝和通知提交共用现有持久事务。保存失败不会先推进游标或弹出未落盘通知。

概览增加独立的目标历史区域，同时展示角色、原计划身份、观察时间和登记时间；空状态、旧服务不支持、加载和失败分别说明。材料历史继续独立展示。
