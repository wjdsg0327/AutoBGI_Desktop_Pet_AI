# 0.2.10 桌面交互与角色状态

日期：2026-10-28。此阶段对应开发规格 §1.1、§8.4、§9.1，继续完善已有桌宠，不增加游戏执行或任务完成推断。

## 角色动作

`frontend/src/pet/actions.ts` 统一桌宠与概览预览的动作选择，优先顺序为拖动、休息策略、当前未读错误、连接失效、真实工作态、挥手、待机。休息属于用户策略门禁，可见勿扰角色保持静止；双击打开面板和右键管理仍可使用。普通单击只在在线空闲时挥手，1200ms 后结束；新错误、工作、失联、隐藏、文档不可见及休眠会取消旧挥手，恢复后不补播。

错误只从当前完整来源的保留正文中选择，要求活动保存资料、实际连接、历史顶层资料与地址、分组地址、协议模式、核验实例以及 `accountId=null` 全部匹配，并且 `kind=error`、`readAt=null`。同来源恢复在线不会自动清除仍未读的错误；明确已读成功后按最新状态回落。鉴权或协议错误已读后仍保持实际离线状态。打开历史、气泡关闭、展示尝试与迟到旧回包都不能代替用户已读。

探测前的错误保持 `unverified`，不能使用旧 Pet V1 快照填充当前实例。Legacy 只沿用服务端同资料的既有回退规则。切换实例只改变当前选择，旧记录仍可查。命令提交成功、材料条件满足及进程存在都不触发任务成功动画。

原生手动操作失败使用当前 `manual:` 错误气泡的短时 warning，按中心的五秒绝对期限退出；持久通知的 warning 由未读历史决定，气泡过期不会清除它。气泡切换、关闭及期限到达会发布新的原生展示版本。

## 单击摘要与原生入口

单击摘要固定四行：实际连接状态、当前配置组、当前路线、上次采集时间。Pet V1 必须与当前核验实例相同，Legacy 必须匹配当前资料；错误来源、账号级快照和未核验实例不展示旧任务。离线使用“历史数据”标识；时间按 RFC3339 解析并显示本机时间，无效或未知时间保持明确提示。配置和路线清理控制字符，并按 Unicode 字符限长，详细内容从概览查看。

原生右键与托盘菜单增加“查看当前状态”“连接设置”“查看通知记录”和“切换鼠标穿透”。穿透开关在调用时读取保存偏好，保留已有恢复入口。

目的地只允许概览、连接管理、设置页通知记录三个固定组合。每次显式请求都增加独立导航版本，即使面板已经可见、请求目标相同也重新定位。普通显隐或业务广播不覆盖用户手动切换的页签。导航与主展示版本在同一锁内提交；锁外再调用原生宿主。启动前请求可锁存，慢创建和重入仍使用最后显示意图。

前端初始化总将 `GetPresentation` 通过版本排序，不再因收到过任意事件而跳过更新快照。通知定位等待设置页挂载；快速离页或新请求会使旧滚动失效。定位和查看均不自动标记已读。

## 拖动与显示器

一个主指针拥有当前手势，第二触点不能移动或结束它。正常松开保留最终位移与一次位置保存；取消、意外丢失捕获、隐藏、休息或卸载会撤销未发操作。迟到的起点返回后不再补发位移或保存，但串行调用链继续保留，下一次拖动可正常读取真实起点。

原生拖动绑定在 UI 闭包执行时重新检查显隐、穿透和休息策略，再在状态锁外调用窗口方法，减少排队调用使用旧门禁的机会。已进入原生调用的系统重入行为仍需实机验证。

`monitorTracker` 记录最近所属显示器的稳定 ID。原 ID 从当前布局消失时，明确在主屏工作区校正，即使另一副屏接替了旧坐标也不能抢占回退。早到的窗口移动事件不覆盖待回退身份；无可用工作区、无效窗口尺寸及当前工作区暂不可用时保留原身份。正常跨屏移动、负坐标和显式重置继续使用既有逐屏几何规则，所有窗口操作在状态锁外执行。

## 验证与交付边界

实际 Vue SFC、动作函数和拖动控制器通过 Node 标准输入验证；Go 纯状态使用实际生产源文件和 overlay，启用 race。验证统计、源码摘要和清理记录见 `desktop-interaction-validation-2026-10-28.json`。本轮没有运行生产 AutoBGI、BetterGI 或游戏，没有读取真实凭据、位置配置或数据库，也没有改变系统网络、电源或显示器设置。

warning 的持久保证仅覆盖当前来源中仍保留的未读错误正文。历史容量裁剪只保存截断标识和勿扰待汇总数，没有被裁剪错误的独立未读摘要；因此被裁剪正文不能继续驱动准确的错误动作，也不能被解释为已读。要完整覆盖裁剪后的错误确认，需要补充独立错误摘要与显式确认合同。

Windows 原生拖动、触摸捕获、混合 DPI、拔屏、快捷键、焦点和真实连接仍待实机验收；本轮不扩大为这些项目通过。已有 250 MB 工作集目标继续未通过，长期性能和可靠游戏完成事件仍未完成。可信库存和生产培养配置替换保持关闭。

本轮新增测试源在验证后单次清理；前端验证没有创建测试文件。历史被自动审批拒绝清理的目标均未重试，也不包含在便携包。0.2.9 ZIP 及其 SHA-256 继续保留；0.2.10 包只包含程序、说明、公开验证记录和许可。
