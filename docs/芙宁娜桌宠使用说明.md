# 芙宁娜桌宠使用说明

## 连接 AutoBGI

1. 启动 AutoBGI，确认启动日志中的实际 HTTP 地址和端口。若默认端口已被占用，服务可能会使用其他端口。
2. 双击桌宠打开设置，进入“连接设置”，填写服务地址和 AutoBGI 运行目录中 `abgiUser.yaml` 的 `auth.api_key`；也可以填写连接昵称。
3. 保存连接后点击“连接日志”，然后在“实时日志”页面查看连接状态和收到的日志。可按需启用启动时自动连接。

密钥只用于桌宠自身连接；默认使用当前 Windows 用户的 DPAPI 加密后保存在程序目录，也可以选择只在本次会话使用。连接地址和规则保存在程序目录的 `config.json`，不会写入 AutoBGI 项目。若更改服务地址，需要重新输入密钥。

支持 HTTP 和 HTTPS；日志列表接口使用 `apiKey` 请求头验证，AutoBGI 的 `/ws/:name` 日志流本身是公开接口，应按自身网络环境限制访问。

## 设置动作和台词

进入“桌宠设置”，添加一条或多条规则。每条规则可以填写多个关键词（用逗号或换行分隔）、选择动作、填写台词，并单独启用或停用。可以调整规则顺序并预览动作；修改后点击“保存规则”。

每收到一行新日志，桌宠按列表顺序匹配第一个启用的规则；同一规则内任意关键词出现即可触发，不区分大小写。台词为最多 300 个字符的单行文字，以桌宠气泡显示；台词留空时显示触发该规则的日志内容。动作包括安静陪伴、开心、挥手、惊讶和难过。

命中后动作和台词展示约 5 秒，然后恢复待机；连续命中会依次展示。待播队列最多容纳 20 条；超出部分不会播放，实时日志页面会显示本次连接中未播放的次数。可通过缩小关键词范围减少重复触发。

## 关键词代办

在规则中开启“命中时创建代办”，选择处理动作。启动一条龙或配置组时，需要从当前在线连接读取并选择真实名称；还可以选择关闭 BGI 和原神，或让 AutoBGI 所在的电脑关机。保存规则后，命中仍会播放原来的动作和台词，同时生成代办；台词留空时，代办使用触发的日志内容。

同一连接的同一规则重复命中会合并为一条，首次命中的内容、动作、目标及来源保持不变，后续修改规则不会改变已生成的代办。不同连接分别保存和显示；切换到相应连接后查看。代办按创建顺序排列，本机当天结束时自动删除，桌宠关闭期间过期的记录会在下次启动时清理。代办保存在当前用户应用数据目录的 `AutoBGI-Pet\todos.json`，不保存 API 密钥。

鼠标在桌宠上连续停留 3 秒后，身边会出现“代办”圆圈和当前连接的数量；没有代办时也可以点击查看。展开后逐条显示内容、来源和实际动作。来源显示连接昵称，未填写时显示“未知”；修改昵称后已有代办也会显示新昵称，不显示连接地址。点击“不管”直接删除；点击“处理”会先持久删除，再向创建它的连接提交一次请求。连接离线或来源不匹配时不能处理，仍可以选择不管。修改连接地址后，原地址的代办会提示来源已变更，只能选择不管。

点击处理一条龙或配置组表示允许切换当前 BGI 任务；一条龙在无法确认 BGI 状态时会拒绝启动。电脑关机调用 AutoBGI 的定时关机任务，该任务会尝试关闭相关软件并安排 60 秒后关机。请求受理不代表操作已经成功；失败、断线或结果未知时请查看原 AutoBGI 的状态或日志，桌宠不会自动重发。桌宠关闭时尚未返回的处理结果无法在下次启动后恢复，原代办也不会自动重建。

“导出规则”会包含代办开关、动作和目标，但不包含连接资料、密钥或本地规则标识。新版可以继续导入旧规则文件，旧规则默认不创建代办；导入后请检查目标并保存规则。

## 饥饿与拾取通知

日志连接成功后，如果一直没有收到新日志，芙宁娜会逐渐表现出饥饿；连续 5 分钟没有新日志时会饿晕。收到任意新日志后她会恢复，重新开始计时。连接中断或暂停时不计算饥饿时间，重新连接后重新开始。

在“桌宠设置”中开启“拾取通知”后，日志出现“交互或拾取”时，芙宁娜会吃小蛋糕，蛋糕上显示对应物品的名称，动作持续 1.5 秒。连续拾取会依次播放；关闭开关会停止拾取动画并清空等待中的拾取。拾取通知默认关闭。

## 日志与桌面操作

- WebSocket 只接收连接建立后追加的内容，不回放历史日志。日志文件轮换、断线和重连期间写入的内容可能漏收。
- 桌宠自动选择服务端列表中的最新日志文件，并定期检查轮换；连接中断后会自动重试。密钥错误时需要修正密钥后重新连接。
- 日志流没有应用层心跳；“日志已连接”表示握手成功且暂未检测到断线，静默断网可能要等系统检测后才显示。
- 可拖动桌宠；单击桌宠查询 BetterGI 当前运行情况，双击打开设置。右键或系统托盘可显示、隐藏桌宠、切换鼠标穿透、断开连接和退出；连接完成后，“启动一条龙”和“启动配置组”会分别展开当前 AutoBGI 返回的名称，点选具体名称即提交一次启动请求。
- 开启鼠标穿透后，Windows 会把桌宠区域的鼠标事件交给下面的窗口，因此桌宠右键不会弹出菜单；请从系统托盘选择“关闭鼠标穿透”或“显示桌宠 / 恢复交互”。

右键菜单的一条龙名称只属于当前在线连接，首次打开时可能显示“正在读取一条龙列表”。名称读取失败、连接切换、BGI 正在运行或状态无法核实时，菜单项会保持禁用或通过桌宠气泡提示；启动成功只表示请求已受理。旧接口超时或断线时结果可能未知，桌宠不会自动重发。

“启动配置组”展示当前连接的全部配置组，包括子目录中的相对名称。点击一个名称即授权启动该组，不弹二次确认；**此操作会打断当前 BGI 任务，关闭现有 BGI 后启动所选配置组**，不受一条龙入口“BGI 正在运行时拒绝启动”的限制。一条龙原有的运行中和状态未知保护不变。

配置组菜单会显示未连接、读取中、空列表或读取失败状态；服务端新增或修改配置组后，可点击“刷新配置组”。点击启动时，桌宠会再次核对当前连接和最新列表，不会把旧连接的名称发送到新连接，也不会改写名称中的空格或子目录路径。配置组与一条龙启动共用防重复门禁，一次请求结束前不能再次启动；等待期间仍可使用现有停止、关闭入口。

配置组启动可能需要较长时间：单次启动 HTTP 请求最多等待 5 分钟，连同列表核验的服务层总期限为 5 分 20 秒。成功提示“配置组启动请求已受理”不代表组内任务已经完成。超时、断线或响应异常时结果可能未知，请先在 AutoBGI 中核对，桌宠不会自动重发；AutoBGI 服务端自身已有的启动重试不受影响。与现有右键一条龙入口一致，显式点选配置组是“仅查询模式”的原生菜单例外，不开放聊天、面板或任意 HTTP 控制能力。

本功能的模拟接口验证与真实环境验收分开记录；当前尚未完成真实 AutoBGI 启动联调和 Windows 原生右键、托盘菜单验收。

桌宠右键和系统托盘的“BGI 快捷键”二级菜单会读取当前在线 AutoBGI 中配置的六个系统快捷键：启动停止 BetterGI、停止当前脚本/独立任务、暂停当前脚本/独立任务、游戏截图、日志与状态窗口展示开关，以及启动停止一条龙。菜单显示对应的按键；未配置的快捷键不可点击。离线、正在读取或读取失败时，菜单会显示相应提示，读取失败后可以点击重试。修改 BGI 配置后，可使用“刷新快捷键”更新菜单；如果点击时发现配置已变化，桌宠也会提示并重新读取。

点击快捷键会向当前 AutoBGI 发送一次按键请求，不会自动重发。桌宠提示请求已发送，只表示服务端已响应，不代表 BetterGI 已执行操作；超时或断线时结果可能未知，请先在 AutoBGI 中核对。按键由 AutoBGI 在其所在电脑上模拟；当前接口按单键发送，组合键是否生效取决于服务端支持。

“BGI 快捷键”菜单还提供“关闭 BGI 和原神”和“关闭原神”两个操作，分别调用当前在线 AutoBGI 的关闭接口；前者会同时关闭 BetterGI 和原神，后者只关闭原神。点击后直接提交一次请求，关闭可能需要一些时间；提示请求已受理不代表进程一定已经退出，超时或断线时请先核对运行状态，不会自动重发。快捷键列表读取失败不影响这两个关闭入口。

## 构建

### 环境要求

- Windows PowerShell。
- Go 1.26 工具链；项目会按 `go.mod` 自动使用 Go 1.26.10。
- Node.js 22.12 或更高版本，以及 npm 10 或更高版本。
- 首次构建需要能下载 npm 依赖和 Wails CLI；Wails CLI 会安装到本项目的 `.tools` 目录，不覆盖系统里的其他版本。

### 构建可执行文件

先关闭正在运行的 `AutoBGI-Pet.exe`，然后在桌宠项目根目录执行：

```powershell
.\scripts\build.ps1
```

默认输出为 `bin\AutoBGI-Pet.exe`。构建过程会依次生成 Windows 资源、更新 Wails 绑定、构建前端并编译 Go 程序。

如果本机已经安装过依赖，后续构建可以跳过 `npm ci`：

```powershell
.\scripts\build.ps1 -SkipInstall
```

### 生成发布压缩包

执行下面的命令生成便携发布包：

```powershell
.\scripts\build.ps1 -Package
```

脚本会在 `bin` 目录生成以下文件：

- `AutoBGI-Pet.exe`：当前版本的 Windows 程序。
- `AutoBGI-Pet-<版本号>-windows-amd64.zip`：便携发布包。
- 同名 `.sha256` 文件：用于核对压缩包完整性。

便携包包含程序、使用说明、第三方声明和角色素材许可文件，不包含本机连接地址、API 密钥、规则配置或历史记录。需要重复打包时，可以组合使用两个参数：

```powershell
.\scripts\build.ps1 -Package -SkipInstall
```

如果不想覆盖已有的 `bin` 输出，也可以指定另一个项目子目录：

```powershell
.\scripts\build.ps1 -Package -OutputDirectory release
```

此时可执行文件、压缩包和校验文件会写入 `release` 目录。构建脚本使用本项目 Go 工具链、Wails 和 npm，不修改 AutoBGI 主项目，也不执行 Maven。角色素材为 AI 生成的同人形象，角色相关权利归原权利人所有。
