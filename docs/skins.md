# 本地精灵皮肤

0.2.4 增加本地 PNG 精灵皮肤导入。打开控制台的“桌宠设置 → 角色外观”，选择已有皮肤，或点击“导入并使用”。文件选择取消后保持原角色；导入失败不会覆盖已安装皮肤。桌宠与控制台预览使用同一选择，预览仍只绘制静态首帧。

## ZIP 文件结构

ZIP 根目录必须正好包含以下三个普通文件，名称和大小写需要一致；不要将外层文件夹一起压缩：

```text
manifest.json
atlas.png
LICENSE.txt
```

`LICENSE.txt` 需要是非空 UTF-8 文本，说明实际素材许可和归属。清单内的许可名称不会自动赋予素材使用权。此版本支持普通静态 PNG，不接受 WebP、APNG、SVG、HTML、脚本、链接文件、目录或其他附带文件。

## 清单示例

以下示例要求 `atlas.png` 为 512 × 256 像素，每格 128 × 128，共四列两行。帧编号从左到右、从上到下，自零开始。图集可含透明像素：

```json
{
  "schemaVersion": 1,
  "id": "my-original-pet",
  "name": "我的原创角色",
  "author": "素材作者",
  "license": "与 LICENSE.txt 一致的实际许可名称",
  "atlas": "atlas.png",
  "frameWidth": 128,
  "frameHeight": 128,
  "columns": 4,
  "rows": 2,
  "scale": 1,
  "anchor": { "x": 0.5, "y": 1 },
  "actions": {
    "idle": { "frames": [0, 1, 2, 3], "fps": 4, "loop": true },
    "wave": { "frames": [4, 5, 6, 7], "fps": 8, "loop": false }
  },
  "fallbackAction": "idle"
}
```

`idle` 必须存在且循环。界面会使用 `wave`、`dragging`、`working`、`warning`、`sleep`、`offline` 等动作，可以按实际素材提供；缺少当前动作时使用 `idle`。也可保留 `success` 等展示动作，但动作仅控制画面，不产生任务成功、账号切换或执行结果。非循环动作播放完毕后回到 `idle`。

`scale` 可省略，默认 1，范围 0.25～2；它是在窗口内绘图的比例，与设置中的原生窗口缩放分别应用。`anchor` 可省略，默认 `{ "x": 0.5, "y": 1 }`，表示居中靠下；两个值均为 0～1。放大超过窗口的部分会裁切。

## 校验限制

| 项目 | 限制 |
| --- | --- |
| 压缩包 | 不超过 8 MiB，实际展开合计不超过 12 MiB |
| `atlas.png` | 不超过 10 MiB，完整 PNG 解码成功；不接受 APNG 或结尾附加数据 |
| 清单与许可 | 各不超过 64 KiB，均为有效 UTF-8 |
| 图片尺寸 | 宽高各不超过 8192，合计不超过 8,000,000 像素 |
| 图集网格 | 帧宽、帧高、行列数为正整数；图像尺寸必须严格匹配 |
| 动作 | 至多 32 个；每个 1～512 帧，FPS 为 1～30，帧号不得越界，`loop` 为显式布尔值 |
| ID | 1～64 字符，小写字母或数字，可用单个连字符分段；不能使用 Windows 设备名及 `abgi-buddy` |
| 动作名 | 小写字母开头，其余可用小写字母、数字、下划线、连字符，最多 32 字符 |
| 名称和作者 | 分别不超过 128 个字符，不含控制字符 |
| 许可名称 | 不超过 256 个字符，不含控制字符 |
| 安装数量 | 至多 64 套导入皮肤，另有内置角色 |

清单拒绝重复字段、未知字段、错误大小写、额外 JSON 内容和不符合类型的值。可省略默认字段，但不能用 `null` 代替。导入同时检查 ZIP 路径、真实读取长度、文件类型及图片内容，不只检查扩展名。

## 保存与恢复

皮肤安装在 `%APPDATA%\AutoBGI-Pet\skins\<id>\`。此路径是宿主内部目录，不向网页开放任意文件读取。安装先完整验证，再写入同目录暂存区并原子改名；相同 ID 不可覆盖，要更新一套皮肤请使用新的 ID。

启动时所选皮肤已损坏或缺失，会回退内置角色并提示。运行中加载失败先尝试内置角色；若内置也暂不可用，保留上一张成功图集。首次就无法加载任何图集时显示“资源暂不可用”文字提示。快速连续换肤、组件卸载或退出时会废弃旧请求，旧错误不会覆盖新角色。关闭控制台会隐藏并保留 WebView，不等于卸载组件。

此版本没有皮肤联网下载、脚本插件或专用删除界面。退出桌宠后可手动删除不再需要的皮肤目录；下次启动会检查缺失项。连接资料导出不包含皮肤或凭据，迁移皮肤需另行保留原始 ZIP 和素材许可。
