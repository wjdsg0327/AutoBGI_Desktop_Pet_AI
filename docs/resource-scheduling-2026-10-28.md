# 0.2.8 恢复快捷键与资源调度

日期：2026-10-28。本文记录桌宠客户端的交互修正及资源调度改进。源码、验证记录和便携程序均位于 `AutoBGI_Desktop_Pet_AI`。

## 恢复快捷键

设置继续只支持 `Ctrl+Shift+P`、`Ctrl+Alt+P`、`Ctrl+Shift+Y` 三组组合。宿主先注册新的组合，成功后才释放此前已注册的组合；冲突时保留原来的恢复入口。

面板分别展示已保存的选择、当前实际注册的组合和注册状态。冲突后改回原先可用的组合会清除快捷键告警，托盘和网络告警独立保留。重试按钮只重试当前已保存的组合，不接受网页传入任意按键；重复点击在 UI 队列中合并。

这项验证使用受控的注册回调，没有注册真实系统快捷键。实际操作系统中的组合占用、托盘恢复和游戏焦点仍需原生验收。

## 精灵动画

渲染器先通过计时器等待下一素材帧的期限，到期后仅请求一次 `requestAnimationFrame`。8 FPS 动作不再按显示器刷新率持续运行 JavaScript 回调。期限由动作起点和真实经过时间计算，回调延迟时直接选择当前应显示的帧。

隐藏、休眠投影、切换动作、静态预览、窗口尺寸变化及卸载都会使旧调度失效。取消包含计时器和 RAF；代次检查拒绝已排入队列但迟到的旧回调。静态面板预览绘制一次后停止，非循环动作结束后继续回到待机。

换肤仍在新描述文件及图片完整验证成功后提交，失败时保留上一次成功图集。调度改动没有放宽同源、描述文件实际读取上限、帧索引、图集尺寸和动作校验。

## PNG 验证缓存

每个皮肤管理器最多保留 32 个成功 PNG 验证结果，只记录完整文件 SHA-256 和尺寸，不保存解码后的像素缓冲区。相同内容再次请求时复用验证结果；改变任意文件内容都会重新验证，不依赖路径、长度或修改时间判断命中。

每次请求仍重新核对目录与文件身份、拒绝链接、限制实际读取长度，并校验本次描述文件、许可与网格尺寸。缓存提交发生在整包验证和安装或读取身份检查全部成功之后，失败请求不能将候选结果写入正式缓存。管理器锁串行化并发读取，避免同一内容同时重复完整解码。

## 验证与边界

最终测试统计、源码摘要和构建信息记录在 `resource-scheduling-validation-2026-10-28.json`；验收汇总见 `acceptance.md` 的 0.2.8 章节。新增临时测试源的实际清理状态以该记录为准。

本轮不重新测量原生进程树内存、CPU、DPI、游戏焦点或八小时耐久。减少唤醒与重复 PNG 解码不能证明常驻内存低于 250 MB，该目标继续保持未通过。没有采用气泡销毁重建、依赖私有布局、强行裁剪工作集或修改固定 Wails 版本。

可靠任务完成事件仍缺少 BetterGI 执行器的结构化生产证据。`executionAvailable`、`inventoryVerified`、`completionEventsAvailable` 继续保持 false；材料满足历史不表示游戏内培养完成。本轮没有运行生产 AutoBGI、读取生产凭据、调用游戏控制或改变系统网络及休眠设置。
