# 0.2.11 裁剪错误的保留与确认

日期：2026-10-28。此阶段延续开发规格 §1.1、§8.4、§9.1 的错误提示与来源隔离，补齐 0.2.10 已记录的正文裁剪缺口。

## 用户可见行为

本地通知正文仍受单来源 200 条、总量 1000 条和 40 个来源的容量限制。实际裁剪一条尚未读过的错误时，该来源独立保留错误数量及最近实际发生时间。角色继续根据当前完整来源的未读正文或有效错误摘要显示警告；关闭气泡、恢复连接、打开历史及勿扰结束都不等于已读。

通知记录展示“未读错误正文已清理”，说明只保留数量和时间，无法恢复原文。用户先选择确认，再点击“确认已知晓”，才提交摘要确认。保留正文继续用单条或同来源已读按钮处理；两类操作互不替代。历史实例的错误可在同一保存资料和地址下明确确认，但不会驱动当前实例动作。

摘要确认绑定完整资料、地址、协议、实例、账号和摘要版本。页面准备确认后，来源、连接代次、摘要数量或版本、筛选、页面选择发生变化，都会撤回本地确认。后端再次核对来源和版本；迟到请求不能清除随后裁剪的新错误。提交失败时保留旧摘要，只有落盘成功后才刷新界面。

## 持久合同

`Journal.notificationErrorRevision` 是日志级、规范十进制的 uint64 字符串，初始为 `"0"`。各来源的 `errorSummary` 为可空的四字段对象：`revision`、`unreadCount`、`quietPending`、`latestAt`。非空摘要要求来源已截断；有效未读摘要必须有实际错误时间。确认后的摘要保留新版本和零计数，时间为空。

每次裁剪未读错误、每次成功确认摘要都会递增全局版本。来源删除、容量淘汰或同名重建不重置该版本，防止旧页面碰巧匹配新摘要。保存也拒绝低于现有磁盘版本的快照。计数或版本溢出时整次操作失败，原日志和指针指向的事实不变。

摘要的最近时间取实际被裁剪错误的最大 `createdAt`，不使用裁剪、恢复或展示时间。前端解析与已持久化的 Go 1.26.10 时间合同一致，兼容 Go 已接受的小时、小数分隔符与时区写法，按实际时刻展示；本地日历年份、长度、无效日期和 Go 零时间仍接受校验。小数按 Go 的前九位纳秒判断，显示采用本机时间精度。

历史 DTO 的 `unreadCount` 保留“当前正文未读数”语义；界面总数另加摘要的未读错误数。摘要确认只扣自己的 `quietPending`；勿扰恢复只清理待汇总标记，保留错误数量、发生时间和版本。摘要有未读错误时，该来源不能因来源容量上限被淘汰。

JSON 恢复拒绝重复字段、字段别名、缺失或多余摘要键、错误类型、非规范版本以及不守恒的待汇总计数。旧版本完全缺少新增字段时迁移为空摘要与零全局版本。旧记录只有 `truncated` 或待汇总数时，无法证明其中是否存在未读错误，保持未知；0.2.11 不反推或伪造历史事实。

## 验证范围

存储真实源码通过 Go 1.26.10 race 三轮：108 个独立命名场景、100 个叶场景，共 324 条命名通过和 300 条叶通过，零失败、零 race。包含旧版迁移、严格 JSON、来源淘汰后保存／重启／重建、旧确认拒绝、磁盘版本回退、溢出原子性和指针隔离。

服务真实源码通过 race：22 条命名通过、20 个叶场景。覆盖两种 205 条勿扰错误的处理顺序、24 路并发同版本确认仅一次成功、历史实例确认、正文独立已读、实际隔离磁盘提交失败及阻断状态。

根验证按独立事实账本检查 1920 次插入、单来源与六来源组合、显式正文已读和摘要确认，并完成 11 次真实文件保存／恢复。每步确认“保留未读错误正文数 + 裁剪未读摘要数”等于独立账本，不复写容量选择算法。

前端使用最终实际 Vue SFC、Pinia、bridge、时间与动作函数，通过 Node 标准输入完成 211 项验证：原 98 项完整回归全部重跑，新增 113 项兼容与确认检查。覆盖来源匹配、计数边界、两步确认、迟到回包、导航、29 种合法时间的正确时刻／界面／确认，以及 48 种非法时间的拒绝。独立审查另外执行 48 项时间、规范版本与零墓碑边界，13 份相关源码摘要保持稳定。旧 116 项分阶段结果已被最终完整回归取代，不计入最终数量。生产源码摘要与构建结果见 `error-retention-validation-2026-10-28.json`。

前端验证没有创建测试源码。服务和根验证新增的测试源及 overlay 已各单次成功删除。存储验证的 `.validation/error-summary-storage-domain-491fb61dc79f49939dc9814ae6cbf56d/error_summary_storage_test.go` 和同目录 `overlay.json` 的单次删除命令被自动审批以 `blocked by policy` 拒绝，未执行且未重试；两文件仍在验证目录，不属于生产包或便携包。历史拒绝清理目标均未触碰。
