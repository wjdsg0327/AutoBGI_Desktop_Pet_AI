# 版本兼容与降级规则

## 当前范围

当前 0.2.5 保留 M0–M2 基础功能、M3 幂等启动/回执/事实事件和 M4 现有业务数据读取及显式只读查询角色选择，并增加独立协商的正式培养队列只读展示；继续支持本地皮肤、脱敏连接资料迁移、断网暂停、按需创建控制台和静态面板角色预览。不要求配置 LLM。原生实测、真实服务联调与性能验收仍独立记录。

## 协议选择

- `legacy`：只访问已核验的旧只读路径，不尝试事件或控制。
- `auto`：首先探测新协议 capabilities；只有明确“不存在/未实现”且旧状态验证成功才降级。
- `pet-v1`：显式要求新协议，缺少协议时应报兼容错误，不能悄悄改用旧接口。
- 认证失败、HTML 登录页、损坏 JSON、必需字段缺失、不兼容主版本均显示明确错误。
- 通用能力声明中的未知字段允许忽略；未知能力保持不可用，不按版本号猜测开放。独立培养队列的版本一正文使用完整字段合同，拒绝未知、重复、缺失字段或隐式零值，后续扩展须另行协商。

## 地址与请求策略

地址仅允许 HTTP/HTTPS，不允许 userinfo、query 或 fragment。固定反向代理基础路径必须保留，例如 `https://host/abgi` 对应 `https://host/abgi/api/index`。
回环地址允许 HTTP；远程默认 HTTPS。局域网明文必须在该连接资料上显式启用，并提示 APIKey 将明文传输。
拒绝重定向，不关闭 TLS 校验，不扫描局域网，不尝试默认 APIKey。
系统浏览器打开的是无密钥 base URL，网页独立处理登录。

## 状态与切换

每次连接、切换资料、修改凭据都会建立新 generation，并取消旧请求。旧 generation 回包不能覆盖新连接快照。
网络异常保留上次快照并标记过期；未知状态不是零收益或已停止。401/403 停止自动重试。
隐藏桌宠、关闭面板、断开连接与退出相互独立；前两个操作不能终止业务任务或发出控制请求。
多份连接资料可以保存，但同时只激活一份，不同时监控多个实例。

轮询、首次协议探测、事件重同步、命令准备与确认使用同一个可取消采样门。较新成功样本取得后，旧样本不能回写快照、确认卡或重同步游标。休眠使在途和排队样本失效，快速恢复也不会接纳休眠前结果；命令仍依赖服务端最终版本核对。

手动配置列表、领域摘要与命令回执另冻结完整来源和能力，并继承同一暂停取消周期。十秒配置/回执读取、三十五秒领域读取结束时均核对期限，忽略取消的适配器也不能提交旧响应。领域取消后不继续读取后续块，失效回执不落盘、不生成通知；合法查询返回事件与 HTTP 合并后的最高阶段。Legacy 无实例编号的正常配置查询仍可使用。

前端手动读取周期覆盖状态、资料、代次与完整能力变化，旧结果和旧错误一并丢弃；字段顺序、revision 与普通心跳不使结果失效。业务摘要在暂停后保留为历史，恢复在线后需要主动刷新。HTTP 410 且精确 COMMAND_EXPIRED 显示保留窗口结束，保留原命令并提示人工核对，不增加重发入口。验证与当前规格缺口见 `manual-read-lifecycle-2026-10-28.md`。

Windows 通过同步原始电源消息按顺序记录挂起/恢复意图，再由单一消费者更新原生展示和采集暂停，避免框架通用事件协程先后颠倒。该编排经过注入消息验证，真实机器电源矩阵尚未验收。非 Windows 只保留通用事件兼容入口，不宣称具备同等原始消息顺序保证。

Windows 额外使用 `NotifyIpInterfaceChange` 和 `NotifyUnicastIpAddressChange` 合并通知，并每十五秒读取本机接口作兜底。工作中的非回环单播接口即视为网络可用，包括局域网和链路本地地址；此判断不代表互联网、DNS 或目标服务器可达。读取异常属于未知，保留上次事实。该逻辑没有外部联网探测。

休眠与本机网络离线是两个独立原因，连接以 `paused`、`SYSTEM_SLEEP` 或 `NETWORK_OFFLINE` 表达。字面回环 IP 与 `localhost` 不因外部接口离线而暂停，其他域名不经过 DNS 判定回环。暂停会取消快照、等待者和 SSE，确认卡失效；最后一个原因消失后进入完整重同步，成功前历史快照继续过期。不借网络恢复重启已鉴权失败、不兼容或主动断开的连接。

## 本地文件迁移与皮肤

连接资料导入导出只走原生文件对话框。schemaVersion 1 JSON 严格白名单，不接受密钥、凭据引用、旧 ID、历史记录或额外字段；实际读取限 64 KiB，拒绝重复键。整批先验证再原子追加，上限二十个连接；新条目强制仅查询、关闭自动连接并等待显式补填密钥，不读取或创建系统凭据，不切换活动连接。取消选择不报告成功。

自定义皮肤采用版本一清单、静态 PNG 与 UTF-8 许可文本，不能执行脚本或指定远程 URL。ZIP 根目录必须正好三个文件，解压前后均有体积上限；PNG 完整解码并核对精灵网格、帧、FPS、缩放和锚点。Windows 设备名、路径穿越、重复文件、符号链接、联接逃逸、APNG 和尾随数据均拒绝。详细格式见 `skins.md`。

皮肤选择由 Go 的 `SelectSkin` 仅更新 `SkinID`，不会把文件选择前的完整旧偏好写回。资源只在固定同源路径读取，导入失败保留已安装包，同 ID 不覆盖；启动缺失项回退内置。切换加载采用代次和取消信号，成功前保留原图，旧错误不能覆盖新选择。WebView 渲染器另对实际清单流施加 64 KiB 上限，拒绝跨来源清单和清单重定向。原生文件对话框、多屏换肤和系统真实网络通知仍需实机验收。

角色选择属于一次手动业务摘要，不改变 profile/generation/实例或任务确认。切换立即清除旧角色数据，列表失败、选择消失或响应身份不匹配不能回退默认。没有 `queryRoles` 能力的旧 PetV1 继续读取原默认角色摘要；显式角色选择在本地返回 `UNSUPPORTED_CAPABILITY`，不发送角色接口请求。扫描档案独立选择，不能凭同名目录认定为该角色库存。

正式队列使用 `/cultivation-queue?presetId=...`，只读计划自身的绑定身份，不使用摘要的查询角色。`plan.revision` 为精确十进制字符串，所有库存及缺口为 null。新客户端遇到缺少该能力的旧服务时隐藏此入口，原有培养摘要继续可读；旧客户端忽略新能力，旧 `/cultivation-plans` 的 `queueAvailable`、`completionEventsAvailable` 继续为 false，SSE 不新增培养事件。

## 通知展示策略

桌面层一次摄入当前完整通知历史，待展示队列最多二十项，超量合并为一个计数摘要。错误优先于启动动作结果和普通状态；只有错误自动抢占已有普通气泡，普通点击也不能覆盖错误或命令结果。已尝试显示且被抢占的通知不重新排队。普通气泡展示五秒，重复状态广播不延长截止时间；原生拖动仅抑制当前气泡，下一条仍按队列推进。

同一上下文的待显示进度合并；当前通知没有可靠 taskId，所以不宣称按游戏任务分组。勿扰期间记录数量，退出只显示一次摘要；隐藏、休眠、关闭气泡会消费并丢弃待显示提醒，恢复不补弹。资料、代次或实例变化清空当前展示与待显示项；最近 4096 个 ID 在上下文间保留去重，记录最多保留六分钟，超过窗口的重放仍由持久事件 journal 约束。过期五分钟、无效时间或超前一分钟的提醒不进入展示队列，不以本地读取时间替代事实发生时间。

通知中心不生成游戏任务终态；启动动作失败、连接错误及本地设置失败均为对应系统事实，不能等同于游戏任务失败。正式培养 FIFO 和完成通知仍缺少可信库存与事务接入，边界见 `domain-audit.md`。

## 启动与事件保证

确认有效期 60 秒，冻结 profile、地址、instanceId、presetId 和 stateVersion，前端不能用布尔值绕过。状态版本随执行目录、配置内容、进程状态和启动占用变化；普通进度变化不会使确认失效。

确认进入后若因快照门或网络等待而过期，最终发送意图落盘前仍会拒绝，不延长确认期限。暂停会取消旧事件流并推进回调代次；快速恢复后的旧事件不能继续推进游标。已知命令终态不被矛盾的迟到终态覆盖，也不据此生成相反通知。

服务端命令日志使用进程间锁与同卷原子替换，先持久登记再派发。去重窗口 24 小时，结果保留 7 天；旧命令墓碑阻止复用 UUID，崩溃后 accepted/executing 恢复 unknown，不自动重新执行。当前日志有 16 MiB 安全上限，超过上限拒绝新增控制并保留证据。

服务端事件游标为 `epoch:sequence`，日志在当前进程内保留最多 24 小时/10000 条；重启更换 epoch，旧游标返回 410 后客户端重新读取快照。客户端在同一持久提交中推进游标、回执、去重及通知尝试，再尝试显示气泡；不承诺跨崩溃的严格恰好一次显示。

最终启动会再次校验配置文件 SHA-256 和目录、读取新鲜进程表，只启动一次。外部程序在启动后改写配置的行为不在现有 BGI 的事务保证内。不会因回执 succeeded、进程退出或材料齐全生成任务/培养完成事件。

## 工具链

- 桌宠使用独立 Go module，不修改 AutoBGI 根目录的 Go 版本或依赖。
- Wails `v3.0.0` 与 `@wailsio/runtime` `3.0.0` 为同一锁定版本；模块元数据要求 Go `1.26.0`。
- 规格初始工具链为 Go `1.26.10`；本机已有 Go `1.27.1`。实际构建使用情况以 `acceptance.md` 记录为准，不把本机较高版本冒充锁定版本验证。
- 本机已发现 Node.js `v24.21.0`、npm `11.19.0`；前端确切依赖由 `package.json` 与 `package-lock.json` 锁定。
- Windows 11 x64 为首发目标；Windows 10、其他系统与 WebView2 缺失行为需单独实测，不由编译成功推导兼容。

## 原生窗口限制

控制台只在主动打开、首次设置或托盘初次创建失败时建立；已配置场景的普通重连不会弹出控制台。首次设置可能激活控制台，业务状态广播不会调用打开面板。关闭仍然隐藏并保留 WebView 与表单草稿，不能把关闭面板描述为释放全部渲染资源。

整窗穿透使用宿主能力，不使用 CSS `pointer-events` 声称实现原生穿透。透明窗口仍可能有矩形命中范围。
多屏、负坐标、混合 DPI、拔屏、休眠唤醒、全屏游戏焦点与托盘恢复必须按 `acceptance.md` 实机清单验收。
浏览器预览仅检查布局与前端行为，不证明桌面功能已通过。
