# 手动查询生命周期与过期回执

日期：2026-10-28。本阶段修改桌宠独立模块，没有修改根 AutoBGI 服务实现，也没有重建冻结的 0.2.14、0.2.13 程序或 ZIP。新的行为需要后续从当前源码构建桌宠后才会生效。

## 查询来源与提交条件

配置列表、业务摘要和已记录命令的回执查询现在共用 `internal/service/manual_read.go`。每次读取在锁内冻结完整连接资料、HTTP 客户端、适配器身份、连接代次、暂停周期和完整能力。实例指针、命令切片、保留策略和资料内的账号指针均深复制，避免原地修改掩盖来源变化。

手动读取继承快照使用的暂停取消源。配置列表和回执保持十秒超时，领域摘要保持三十五秒超时；暂停、停止连接或超时会取消请求。返回前再次核对所有来源、在线状态与上下文期限，适配器即使忽略取消也不能提交旧结果。Legacy 配置列表仍允许没有实例编号；无法安全比较的适配器动态值在发出请求前受控拒绝。

领域摘要在相邻网络块之间检查取消，已经超时或暂停后不继续读取背包、收益或培养资料。同一读取内的普通领域失败仍可以返回其他已取得的块；角色核对失败不回退到另一角色。此阶段没有改变角色选择、库存未知值或执行能力边界。

回执查询失效或失败时保留查询前的已知回执，并返回错误；失效结果不写本地 journal，也不生成通知。合法查询仍使用已有阶段合并规则，返回实际提交后的最高阶段，因此查询期间收到的事件终态不会被迟到的 accepted 回包降级。准备和确认启动的发送流程没有在本阶段修改。

## 界面行为

状态仓库单独维护手动读取周期。连接代次、活动及实际连接资料、完整脱敏资料、能力或连接状态改变时作废旧请求；能力对象的字段顺序、普通 revision、心跳和业务进度不改变该周期。配置列表、规则问答、回执查询及其补读状态都核对周期，旧成功结果和旧错误均丢弃。最终显示错误时再次检查周期，覆盖内外层 Promise 之间的微任务切换。

来源或能力变化清除旧列表和问答；暂停仅作废尚在等待的答复，已完成对话继续保留。业务摘要在来源变化时清除所有上下文，在暂停等状态周期变化时停止等待、保留已有摘要和选择并标为历史；恢复在线不会将它自动标成新数据。当前来源发生真实读取失败时保留上一次列表或摘要，供用户核对时间后主动刷新。

## 命令过期

客户端只有同时收到 HTTP 410 和精确 `COMMAND_EXPIRED` 才显示“该命令已超过服务端保留窗口，请在 AutoBGI 核对原记录；不会自动重发”。文案来自本地，不显示远端未经处理的正文。其他 HTTP 状态或其他错误码沿用原处理。

过期是服务端去重或结果保留窗口结束，不是新的命令状态。本地已知回执和服务端墓碑继续保留，客户端不因 410 创建新命令、重发原请求或将未知结果推断为失败。
