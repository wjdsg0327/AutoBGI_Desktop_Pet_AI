# 0.2.12 显示器布局变化的位置恢复

日期：2026-10-28。本阶段继续实现开发规格 §8.4，处理运行期间显示器工作区改变时的相对位置。

## 位置合同

桌宠保存相对工作区左上角的整数逻辑像素偏移。显示器移动到桌面另一侧、任务栏改变工作区或分辨率改变时，只要本次枚举仍能识别原显示器，就先把该偏移应用到它的新工作区，再在该工作区内夹取。空间缩小时，以夹取后实际接受的位置作为下一次恢复起点；不会按比例放大偏移。

原显示器消失时回到当前主屏工作区，不根据旧坐标选择恰好占据原位置的另一块副屏。空枚举、无效窗口尺寸或原显示器暂时返回无效工作区时，保留尚未消费的锚点，等待有效数据。

运行时锚点按值保存显示器标识、工作区和偏移。布局尚未校正时，提前到达的移动通知不能覆盖旧锚点或保存错误偏移。重置位置、启动恢复和显式拖动分别建立当前意图；普通同屏和跨屏拖动继续更新位置。

启动位置在注册窗口事件之前只读取一次。页面尚未就绪时的移动消息或屏幕检查不能先覆盖未恢复的位置；迟到的页面就绪事件也不能重新加载文件，覆盖已经接受的重置或拖动。没有有效保存位置时，默认重置同样作为待处理意图，等待有效工作区。

位置读取、屏幕枚举、状态决策和原生位置写入在同一 UI 调用中处理。宿主锁只保护纯状态，原生窗口调用与位置落盘在锁外执行。屏幕监视使用同一份枚举判断变化并校正，避免先后两次枚举代表不同布局。

位置文件继续使用版本 1 的 `monitor`、`x/y`、`relativeX/relativeY`，不迁移或读取连接凭据。Wails 当前实现的显示器标识来自运行时 HMONITOR；此标识不构成跨重启不变的硬件身份保证。

## 验证范围

最终验证数量、被测源码摘要和构建结果见同目录的 `monitor-layout-validation-2026-10-28.json`。

独立纯状态验证使用实际 `monitor_state.go` 与 `geometry.go`，在 Go 1.26.10 下执行 race 三轮：61 个独立命名、54 个叶场景，共 183 条命名通过和 162 条场景通过，零失败及竞态报告。预期坐标来自独立数值夹具，覆盖负坐标迁移、任务栏和工作区变化、连续布局变更、窗口放大与恢复、早到移动、原屏移除、无效枚举、显式重置／恢复／拖动锚点、值快照及布局签名。

宿主控制流验证从最终生产源码提取 13 个完整方法和 `Attach` 的位置初始化前缀，使用实际纯几何源码及合成窗口、屏幕和内存存储。21 个叶场景重复三轮，共 63 条场景通过；包含父级测试共 75 条命名通过，零失败及竞态报告。覆盖启动预读、提前移动与校正、待恢复屏幕失效及移除、默认位置等待、早期显式意图与迟到就绪事件、无效手势，以及 120 帧拖动不逐帧写盘。32 调用者在外部串行门下运行；原生与存储替身用 `TryLock` 检查所覆盖的调用没有持有宿主锁。

该宿主验证把 UI 调用替换为同步函数，并使用最小宿主类型和布尔拖动门禁替身；它不验证真实偏好门禁、Wails 消息队列或真实文件持久化。独立审查另核对提取的方法体、替换边界和原始日志，并完成宿主调用路径与锁定 Wails 本地源码的静态审查。

Go 1.26.10 全包 vet/build、TypeScript 与 Vite 92 模块构建通过。Wails/runtime 固定为 3.0.0，生成 46 个方法与 48 个模型；Windows 文件版本为 0.2.12.0，产品版本为 0.2.12。124 份生产输入在构建前后摘要一致。

合成显示器检查不调用原生窗口，不读取当前用户的实际位置文件，也不改变显示设置。宿主集成审查依据项目锁定的 Wails 3.0.0 本地源码；纯状态验证及源码审查不能替代 Windows 原生实测。
